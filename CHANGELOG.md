# Changelog

- Expanded the initial missing-revenue exercise into three independent incidents covering
  ingestion completeness, SQL join grain and business-day timezone boundaries.
- Added a responsive local investigation dashboard with source tables, check results,
  progressive hints, source contracts, per-incident notes and Markdown export.
- Added fresh-process evaluation of saved learner code and a spoiler-gated reference view.
- Added a narrated, captioned 1080p walkthrough explaining all three repairs, playable locally.
- Added a CLI for environment checks, incident demos, acceptance checks and JSON evidence.
- Expanded to 27 acceptance checks and 14 application regression checks, with browser QA.
- Added Windows/Linux CI across Python 3.11–3.15 and a Chromium interaction job.
- Added a Windows launcher, setup/troubleshooting guide, contribution guide, issue template,
  reference explanations, synthetic fixtures, and reproducible media-production sources.
- Preserved the initial `python -m lab.demo` command and INC-001 learner interface.

This is a local educational project. All three incidents and reference solutions are free under MIT.
